### Research Findings
**Generator Pipeline**: `generateAll()` in `platforms/opencode/generator/index.ts` calls `loadCoreSkills()` → `transformSkillToArtifact()` → `writePlugin()` → `validateGeneratedOutput()`. Output at `platforms/opencode/output/`. `ROOT_DIR` resolves to repo root. No existing registry code.

**CLI Removal Surface**: 6 files to delete (update/3, sync/1, install/platforms/2). 2 files to modify (cli/src/index.ts, install/index.ts). No test files reference these commands. `backup.ts` imports shared utils used elsewhere — safe to delete.

**Validate Command**: Inline Zod schemas (`MarketplaceSchema`, `MarketplacePluginSchema`). `validateMarketplace()` pattern: load → parse JSON → schema validate → semantic checks. `detectValidationType()` only handles `.json`, NOT `.jsonc`.

**OCX Registry Format** (from local example + librarian research): Required top-level: `$schema`, `name`, `version`, `author`, `components[]`. Components: `name`, `type`, `description`, `files[]`. `additionalProperties: false` — no `namespace` field. JSONC is a superset of JSON — `JSON.stringify()` with `.jsonc` extension is valid.

**Documentation References**: README.md (lines 135-136 list update/sync), docs/cli.md (lines 90-136 define update/sync), AGENTS.md (line 24 lists CLI commands), cli/AGENTS.md (command table).
